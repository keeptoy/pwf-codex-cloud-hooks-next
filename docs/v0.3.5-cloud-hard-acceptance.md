# v0.3.5 Cloud hard acceptance

本文件只保存 v0.3.5 已完成的版本增量与不可变 Cloud/Release 证据。稳定执行协议、黑盒提示词、停止条件和
evidence schema 只见 [`Cloud hard acceptance template`](cloud-hard-acceptance-template.md)；本文件不复制模板脚本。

development bootstrap 的 64 位 zero hash 保持 fail closed。最初 Source/Candidate Cloud hard acceptance 已在
zero-hash candidate `v0.3.5-dev` 上完成，随后又在 sealed source 上复验；两次结论都只通过显式 candidate
ZIP URL/SHA override 安装，不反向冒充 Published Release 通道。

<a name="v0-3-5-acceptance-scope"></a>

## 1. 本版本验收增量

- notice 与四个 pinned upstream runtime 的 byte-for-byte pristine 事实一致，manifest notice hash、installer
  projection 与 deterministic ZIP 共同闭合；
- exact current id/source inventory guard 继续拒绝未准入 Phase 4 文件；runtime bundle、installed snapshot、
  Release allowlist、Host ABI、trusted graph 与 production dispatch 不变；
- 通用 package/repository 测试从当前 machine identity 派生 candidate 与 inventory，不复制当前版本或 entry 数量；
- 本次验收增量没有改写 B～E 黑盒提示词，Source/Candidate setup 使用模板
  [`4.1`](cloud-hard-acceptance-template.md#source-candidate-setup)，post-resume deep check 使用模板
  [`9.1`](cloud-hard-acceptance-template.md#source-candidate-deep-check)。

本版本不授予 Product Phase 4，也不授权 contract/Release-v2 implementation。
