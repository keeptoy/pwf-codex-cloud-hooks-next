## 0. 执行路线

当前只能维护本文和完成本地 Release gate，不能执行第 4 节的公开资产 setup。只有第 1 节中的 source、
ZIP 和 bootstrap 字段全部替换为精确值，且第 3 节标记 `PASS` 后，才允许使用公开 Release 通道：

1. 在全新 Codex Cloud 环境选择 Node 22，并 Reset cache 或创建新环境。

4. 保存原始输出和第 10 节摘要；任一步失败立即停止，不 repair 掩盖失败。

setup 结束后由新的 agent/task 验证。

## 2. 硬停止条件

遇到任一情况立即停止并保存完整输出：

- 第 3 节 R4 仍为 `PENDING`，或 Release/重新下载字段尚未写入精确结果；
- tag/source、Release URL、ZIP/bootstrap filename、size 或 SHA 之间不一致；
- GitHub Release 不是 exact `v0.3.2`，或资产不是恰好一个 ZIP 加一个外部 bootstrap；
- Node major 不是 22，或环境复用了已有 `/opt/codex/hooks/planning-with-files`；
- bootstrap、doctor、Managed policy、pristine Skill 或 installed inventory 校验失败；
- B～E 缺少生成回复前的 Runtime 自动注入证据；
- real Resume 没有 catch-up、tail marker、canonical plan，或顺序错误；
- post-resume doctor 不健康、可 repair、存在 error/blocker、inventory 漂移或 snapshot residue。

失败后不得修改/覆盖同一 tag 或资产，不得放宽断言、手工执行 adapter 伪造黑盒输出，也不得 repair 后
继续计为同一次 PASS。任何字节修复都使用新身份并重新开始 seal/publication/Cloud gate。

## 9. F：post-resume doctor、inventory、policy 与 residue

E2 PASS 后，在仓库 workspace 运行：

```bash
set -Eeuo pipefail

PACKAGE_ROOT="$(git rev-parse --show-toplevel)"
DOCTOR_JSON="$(node "$PACKAGE_ROOT/install.js" doctor --json \
  --codex-home /opt/codex \
  --skill-root "$HOME/.agents/skills/planning-with-files" \
  --managed-requirements /etc/codex/requirements.toml)"
printf '%s\n' "$DOCTOR_JSON"

python3 - "$DOCTOR_JSON" <<'PY'
import json
import pathlib
import sys
import tomllib

doctor = json.loads(sys.argv[1])
assert doctor["healthy"] is True
assert doctor["repairable"] is False
assert doctor["errors"] == []
assert doctor["blockers"] == []

runtime = pathlib.Path("/opt/codex/hooks/planning-with-files")
manifest = json.loads((runtime / "installed-manifest.json").read_text(encoding="utf-8"))
expected = sorted(item["path"] for item in manifest["runtime_files"])
actual = sorted(
    str(path.relative_to(runtime)).replace("\\", "/")
    for path in runtime.rglob("*")
    if path.is_file() and path.name != "installed-manifest.json"
)
assert manifest["installer_version"] == "0.3.2"
assert expected == actual
assert len(actual) == 11

policy = tomllib.loads(pathlib.Path("/etc/codex/requirements.toml").read_text(encoding="utf-8"))
for event in ("SessionStart", "UserPromptSubmit"):
    groups = policy["hooks"][event]
    assert len(groups) == 1
    handlers = groups[0]["hooks"]
    assert len(handlers) == 1
    command = handlers[0]["command"]
    assert "hook_adapter.py" in command
    assert "owned-plan.py" not in command
    assert "owned-catchup.py" not in command

print("POST_RESUME_DOCTOR=PASS")
print("INSTALLER_VERSION=0.3.2")
print("INSTALLED_RUNTIME_FILES=11")
print("MANAGED_POLICY=ADAPTER_ONLY")
print("INSTALLED_RUNTIME_INVENTORY=" + json.dumps(actual, ensure_ascii=False))
PY

SNAPSHOT_BASE="${TMPDIR:-/tmp}/pwf-codex-cloud-hooks/snapshots"
LEFTOVERS=0
if [ -d "$SNAPSHOT_BASE" ]; then
  LEFTOVERS="$(find "$SNAPSHOT_BASE" -mindepth 1 -maxdepth 1 -type d -name 'pwf-snapshot-*' | wc -l)"
fi
test "$LEFTOVERS" -eq 0
printf 'SNAPSHOT_LEFTOVERS=0\n'
printf 'V032_POST_RESUME=PASS\n'
```
