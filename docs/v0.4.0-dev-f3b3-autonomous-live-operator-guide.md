# v0.4.0-dev F3B3 autonomous Cloud 验收：新手操作手册

本文是一份完整、独立的操作手册。操作者不需要再拼接 F3 总 runbook 或 F3B2 手册。它只覆盖已经在本地物化、
但尚未执行真实 Cloud live 的 F3B3 autonomous 链：

```text
A_BASE → A_PREP → A_ARM → A_DISARM → A_REPREP → A_REARM
```

本手册冻结的是 exact refs、candidate、Cloud 顺序、提示词、只读校验和 evidence record。它不是 live PASS 记录，
也不授权模型 push、PR、自动修复、rollback、Release 或进入 F3B4/F3C。

<a name="f3b3-one-minute-model"></a>

## 1. 一分钟理解这次验收

F3B2 已证明 smart 可以在 Cloud 中启用、退出和重新启用。F3B3 要验证更严格的 autonomous：

- 未激活时，即使 mode、nonce、attestation 已经准备好，production 仍必须使用 legacy；
- 激活后，production 必须同时绑定 exact task digest、nonce 和零 ledger 摘要；
- autonomous 不能暴露 raw `progress.md`；
- task 被改动但未重新 attestation 时，只允许 canary，不能回退 legacy 或注入部分正文；
- disarm 后修改 task，必须同步轮转 nonce 和 attestation，再单独 re-arm；
- `A_ARM` 和 `A_REARM` 都要各自证明一次真实 Resume。

Cloud 不创建这些计划或 machine state。所有正向状态都已经在本地 validation refs 中提交；Cloud 只 checkout、
安装 frozen runtime、观察 Host、运行只读 probe 并生成 disposable `/tmp` evidence。唯一写 workspace 的负向步骤是
`A_ARM_TAMPER` 中追加一个冻结 sentinel，收证后直接销毁整个环境。

| `A_REPREP` | `5b20eb749c77dc1ac825202ca783dc7b8d938b58` | `autonomous_prepared` | `legacy` | 只改 task、nonce、attestation |

固定内容身份：

| 对象 | Initial (`A_PREP/A_ARM/A_DISARM`) | Reprepared (`A_REPREP/A_REARM`) |
|---|---|---|
| task SHA-256 | `415295db8617e87d8d63b94c891a7e1a1494f63024c96bba0993239564e9b552` | `2f5cd2dcb0d5ce69fb000a97550096e1421e1cd6ad5569d570777cb744144878` |
| nonce | `d7d00d0fcb799f3f` | `c748f8700d4bfcd3` |

### 三层状态怎么读

这三项不能混成一句“已经启用”：

| 字段 | 回答的问题 | 例子 |
|---|---|---|
| `WORKSPACE_STAGE` | 刚才做了哪一步？ | `A_DISARM` |
| `REPOSITORY_STATE` | 当前计划目录的 machine-state 文件组合是什么？ | `autonomous_prepared` |
| `EFFECTIVE_PROFILE` | installed production 最终选择哪个 renderer？ | `legacy` |

例如 `A_DISARM` 的完整语义是：刚删除 activation；mode、nonce 和 attestation 仍在，所以仓库是
`autonomous_prepared`；但 commit point 不存在，所以 production 必须运行 legacy。actual profile 只能由 installed
production probe 证明，不能由 stage 名、文件外观或本手册 expected 值自证。

## 3. 手册 commit 后，哪些值会变

| 对象 | 是否变化 | 原因 |
|---|---|---|
| `0.4.0-dev` 当前 HEAD | 会 | 本手册、测试和状态回补会形成新的开发分支 commit |
| `A_BASE` runtime-source HEAD | 不会 | 已冻结为独立 validation ref |
| `A_PREP…A_REARM` 五个 HEAD | 不会 | 已冻结的 validation DAG 不跟随开发分支移动 |
| candidate SHA-256 | 不会 | 本轮只改 Release-excluded docs/tests/planning |

共同 candidate 精确为 22 entries、85,533 bytes、SHA-256
`df60010402d1faf937d82a66007bd6a7d78f557b8da41a14ab283922c9a4494c`。如果 production、contract、bundle、
installer 或其他 ZIP 输入变化，必须停止并重新冻结整条链；不得只把新算出的 hash 抄回手册。

## 4. push 前本地只读核对

在仓库根目录运行下面的 PowerShell。它核对 refs、direct-parent、exact path、task/attestation/nonce、无 tamper ref
和 candidate identity。expected 值来自已经审核的本地物化结果，不由本次构建自行批准。

```powershell
$ErrorActionPreference = 'Stop'

$scope = '.planning/2026-08-16-phase-4-f3b3-autonomous-materialization'
$refs = [ordered]@{
  'validation/v0.4.0-dev-f3b3-runtime-source' = 'a6fa03159a442b917f893fc51a7e3ed45b37371a'
  'validation/v0.4.0-dev-f3b3-autonomous-prep' = 'd107c1cc53199415cc704553dafeab757060ae9e'
  'validation/v0.4.0-dev-f3b3-autonomous-arm' = 'f43a744cbac7f7056d4efbf9b5cbd676bc1e4091'
  'validation/v0.4.0-dev-f3b3-autonomous-disarm' = '98b6f138497af244563541ec655a1111198f0c36'
  'validation/v0.4.0-dev-f3b3-autonomous-reprep' = '5b20eb749c77dc1ac825202ca783dc7b8d938b58'
  'validation/v0.4.0-dev-f3b3-autonomous-rearm' = '32b13b018176cd3bbaa15480864bf168754e5f67'
}
foreach ($entry in $refs.GetEnumerator()) {
  $actual = (git rev-parse $entry.Key).Trim()
  if ($LASTEXITCODE -ne 0 -or $actual -ne $entry.Value) {
    throw "ref mismatch: $($entry.Key): expected $($entry.Value), got $actual"
  }
  "PWF_F3_LOCAL_REF=$($entry.Key) HEAD=$actual"
}

$relations = @(
  @{ Child=$refs['validation/v0.4.0-dev-f3b3-autonomous-prep']; Parent=$refs['validation/v0.4.0-dev-f3b3-runtime-source']; Paths=@("A`t$scope/.attestation", "A`t$scope/.mode", "A`t$scope/.nonce") },
  @{ Child=$refs['validation/v0.4.0-dev-f3b3-autonomous-arm']; Parent=$refs['validation/v0.4.0-dev-f3b3-autonomous-prep']; Paths=@("A`t$scope/.pwf-codex-managed") },
  @{ Child=$refs['validation/v0.4.0-dev-f3b3-autonomous-disarm']; Parent=$refs['validation/v0.4.0-dev-f3b3-autonomous-arm']; Paths=@("D`t$scope/.pwf-codex-managed") },
  @{ Child=$refs['validation/v0.4.0-dev-f3b3-autonomous-reprep']; Parent=$refs['validation/v0.4.0-dev-f3b3-autonomous-disarm']; Paths=@("M`t$scope/.attestation", "M`t$scope/.nonce", "M`t$scope/task_plan.md") },
  @{ Child=$refs['validation/v0.4.0-dev-f3b3-autonomous-rearm']; Parent=$refs['validation/v0.4.0-dev-f3b3-autonomous-reprep']; Paths=@("A`t$scope/.pwf-codex-managed") }
)
foreach ($relation in $relations) {
  $parent = (git rev-parse "$($relation.Child)^").Trim()
  if ($parent -ne $relation.Parent) { throw "parent mismatch: $($relation.Child)" }
  $actualPaths = @(git diff-tree --no-commit-id --name-status --no-renames -r $relation.Child)
  if ((Compare-Object $relation.Paths $actualPaths)) { throw "path mismatch: $($relation.Child)" }
}

$states = @(
  @{ Head=$refs['validation/v0.4.0-dev-f3b3-autonomous-prep']; Task='415295db8617e87d8d63b94c891a7e1a1494f63024c96bba0993239564e9b552'; Nonce='d7d00d0fcb799f3f' },
  @{ Head=$refs['validation/v0.4.0-dev-f3b3-autonomous-arm']; Task='415295db8617e87d8d63b94c891a7e1a1494f63024c96bba0993239564e9b552'; Nonce='d7d00d0fcb799f3f' },
  @{ Head=$refs['validation/v0.4.0-dev-f3b3-autonomous-disarm']; Task='415295db8617e87d8d63b94c891a7e1a1494f63024c96bba0993239564e9b552'; Nonce='d7d00d0fcb799f3f' },
  @{ Head=$refs['validation/v0.4.0-dev-f3b3-autonomous-reprep']; Task='2f5cd2dcb0d5ce69fb000a97550096e1421e1cd6ad5569d570777cb744144878'; Nonce='c748f8700d4bfcd3' },
  @{ Head=$refs['validation/v0.4.0-dev-f3b3-autonomous-rearm']; Task='2f5cd2dcb0d5ce69fb000a97550096e1421e1cd6ad5569d570777cb744144878'; Nonce='c748f8700d4bfcd3' }
)
foreach ($state in $states) {
  $task = (python -c "import hashlib,subprocess,sys; print(hashlib.sha256(subprocess.check_output(['git','show',sys.argv[1]])).hexdigest())" "$($state.Head):$scope/task_plan.md").Trim()
  $attestation = (git show "$($state.Head):$scope/.attestation").Trim()
  $nonce = (git show "$($state.Head):$scope/.nonce").Trim()
  if ($task -ne $state.Task -or $attestation -ne $state.Task -or $nonce -ne $state.Nonce) {
    throw "state identity mismatch: $($state.Head)"
  }
}

git show-ref --verify --quiet refs/heads/validation/v0.4.0-dev-f3b3-autonomous-tamper
if ($LASTEXITCODE -eq 0) { throw 'tamper ref must not exist' }

$candidate = Join-Path ([System.IO.Path]::GetTempPath()) ("pwf-f3b3-" + [guid]::NewGuid() + '.zip')
try {
  python tools/build_release.py build --output $candidate
  if ($LASTEXITCODE -ne 0) { throw 'candidate build failed' }
  python tools/build_release.py check --archive $candidate
  if ($LASTEXITCODE -ne 0) { throw 'candidate check failed' }
  $actualSha = (Get-FileHash -Algorithm SHA256 -LiteralPath $candidate).Hash.ToLowerInvariant()
  $expectedSha = 'df60010402d1faf937d82a66007bd6a7d78f557b8da41a14ab283922c9a4494c'
  if ($actualSha -ne $expectedSha) { throw "candidate mismatch: expected $expectedSha, got $actualSha" }
  "PWF_F3_LOCAL_CANDIDATE_SHA256=$actualSha"
} finally {
  Remove-Item -LiteralPath $candidate -Force -ErrorAction SilentlyContinue
}
```

## 5. 维护者 push 与远端只读核对

本地最终 commit 完成后，只由维护者执行远端写入：

```bash
git push origin 0.4.0-dev
git push origin validation/v0.4.0-dev-f3b3-runtime-source
git push origin validation/v0.4.0-dev-f3b3-autonomous-prep
git push origin validation/v0.4.0-dev-f3b3-autonomous-arm
git push origin validation/v0.4.0-dev-f3b3-autonomous-disarm
git push origin validation/v0.4.0-dev-f3b3-autonomous-reprep
git push origin validation/v0.4.0-dev-f3b3-autonomous-rearm
```

然后只读核对；第一列必须逐项等于第 2 节 exact HEAD：

```bash
git ls-remote --heads origin \
  refs/heads/validation/v0.4.0-dev-f3b3-runtime-source \
  refs/heads/validation/v0.4.0-dev-f3b3-autonomous-prep \
  refs/heads/validation/v0.4.0-dev-f3b3-autonomous-arm \
  refs/heads/validation/v0.4.0-dev-f3b3-autonomous-disarm \
  refs/heads/validation/v0.4.0-dev-f3b3-autonomous-reprep \
  refs/heads/validation/v0.4.0-dev-f3b3-autonomous-rearm
```

不得创建 tamper ref，也不得继续向这些 validation refs 增加 commit。任何漂移都使已审计 DAG 失效。

## 7. Workspace 前置检查和固定计划

上面的 setup/maintenance 已经在模型收到第一条提示词之前完成 workspace preflight，不要再粘贴第二份 preflight。
Cloud checkout 本身已经包含 exact active pointer、plan records 和当前 stage state。模型不得 init、repair、re-attest、
自动 commit 或“缺什么补什么”。

固定 plan ID 是 `2026-08-16-phase-4-f3b3-autonomous-materialization`，exact 标题是
`# Task Plan: Phase 4 F3B3 autonomous live chain`。setup 必须打印 actual stage、HEAD、task SHA、nonce、repository state
和 expected profile。任何不一致都应在模型开始前非零退出；这时停止，不发送黑盒提示词。

## 8. Cloud 六轮固定顺序

只按下面顺序执行，不合并任务，不调换顺序：

1. `A_PREP` cold Fresh：选择 prep ref，reset cache，实际 profile 必须 legacy。
2. `A_ARM` cold Fresh + real Resume：选择 arm ref，Fresh 必须 autonomous；随后恢复同一会话，观察 resume。
3. `A_ARM_TAMPER` disposable：重新从 exact arm ref 新建 cold task；先证明 clean autonomous，再执行第 10 节唯一 edit，
   follow-up 必须 canary-only，收证后销毁环境。
4. `A_DISARM` cold Fresh：选择 disarm ref，实际 profile 必须恢复 legacy。
5. `A_REPREP` cold Fresh：选择 reprep ref，新 task/nonce/attestation 已就位但实际 profile仍为 legacy。
6. `A_REARM` cold Fresh + real Resume：选择 rearm ref，必须使用新 digest/nonce 的 autonomous；随后恢复同一会话观察 resume。

每个正向 Fresh task 只有一个顺序：

1. setup/maintenance transaction 和 workspace preflight取得明确最终 `exit_code=0`；
2. 发送第 9.1 节第一条无工具提示词，保存真实 Host 注入；
3. 发送最终只读校验提示词，只执行第 11.1 节脚本并等待最终 exit code；
4. 保存原始 stdout/stderr，生成并校验第 12 节 evidence record。

`A_ARM_TAMPER` 严格按第 10 节独立顺序。异步工具返回 `session_id` 或没有最终 `exit_code` 时必须继续轮询；
没有最终状态只能报告 `INCOMPLETE/UNKNOWN`，不得用部分 stdout 或缺少 PASS 猜成败。

## 13. 停止条件与完成定义

任一情况立即 `STOP_AND_REVIEW`：

- workspace/source/candidate identity 漂移，worktree 在正常 stage 不 clean，或 tamper 多出第二个 dirty path；
- `A_PREP/A_DISARM/A_REPREP` 不是 legacy，或 `A_ARM/A_REARM` 不是 autonomous；
