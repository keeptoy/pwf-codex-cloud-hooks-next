## 本版本验收增量

- notice 与四个 pinned upstream runtime 的 byte-for-byte pristine 事实一致，manifest notice hash、installer
  projection 与 deterministic ZIP 共同闭合；
- exact current id/source inventory guard 继续拒绝未准入 Phase 4 文件；runtime bundle、installed snapshot、
  Release allowlist、Host ABI、trusted graph 与 production dispatch 不变；

  [`4.1`](cloud-hard-acceptance-template.md#source-candidate-setup)，post-resume deep check 使用模板
