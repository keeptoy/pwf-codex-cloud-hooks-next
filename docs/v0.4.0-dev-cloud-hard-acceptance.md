# v0.4.0-dev Cloud hard acceptance

本文件只描述 `v0.4.0-dev` 的版本验收增量。稳定执行协议、黑盒提示词、停止条件和 evidence schema 只见
[`Cloud hard acceptance template`](cloud-hard-acceptance-template.md)；实际验收完成后再写入不可变证据。

Source/Candidate Cloud hard acceptance 尚未开始。development bootstrap 使用 64 位 zero hash 并 fail closed；
它只能通过显式 candidate ZIP URL/SHA override 安装，不代表 tag、Release 或 Published Release 资产。

<a name="v0-4-0-dev-acceptance-scope"></a>

## 本版本验收增量

- F0 只建立 `v0.4.0-dev` package/Release identity、外部 bootstrap 和 candidate/accepted 治理窗口；
- runtime bundle、installed snapshot、Release entry allowlist、Host ABI、trusted graph、production dispatch 与
  pinned upstream runtime bytes 继续保持 `v0.3.5` accepted baseline 语义；
- exact current id/source inventory guard 继续拒绝未准入文件，development bootstrap 默认 checksum 必须拒绝执行；
- 本次验收增量没有改写 B～E 黑盒提示词，Source/Candidate setup 仍使用模板
  [`4.1`](cloud-hard-acceptance-template.md#source-candidate-setup)，post-resume deep check 仍使用模板
  [`9.1`](cloud-hard-acceptance-template.md#source-candidate-deep-check)。

该 development candidate 不授予 F1A、F1B、behavior activation、seal、publication、promotion 或 rollback
变更；后续 gate 必须由新的活动 task plan 单独授权。
