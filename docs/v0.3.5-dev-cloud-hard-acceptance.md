# v0.3.5-dev Cloud hard acceptance

本文件只描述 v0.3.5-dev 的版本验收增量。稳定执行协议、黑盒提示词、停止条件和 evidence schema 只见
[`Cloud hard acceptance template`](cloud-hard-acceptance-template.md)；尚未完成的执行进度只写活动 Release
task plan，不在这里预建结论。

Source/Candidate Cloud hard acceptance 尚未开始。development bootstrap 使用 64 位 zero hash 并 fail closed；
它只能通过显式 candidate ZIP URL/SHA override 安装，不代表 tag、Release 或 Published Release 资产。

<a name="v0-3-5-dev-acceptance-scope"></a>

## 本版本验收增量

- notice 必须与四个 pinned upstream runtime 的 byte-for-byte pristine 事实一致，且 manifest notice hash、
  installer projection 与 deterministic ZIP 必须共同闭合；
- exact current id/source inventory guard 继续拒绝未准入 Phase 4 文件；runtime bundle、installed snapshot、
  Release allowlist、Host ABI、trusted graph 与 production dispatch 不变；
- 通用 package/repository 测试从当前 machine identity 派生 candidate 与 inventory，不复制当前版本或 entry 数量；
- 本次验收增量没有改写 B～E 黑盒提示词，Source/Candidate setup 仍使用模板
  [`4.1`](cloud-hard-acceptance-template.md#source-candidate-setup)，post-resume deep check 仍使用模板
  [`9.1`](cloud-hard-acceptance-template.md#source-candidate-deep-check)。

该 candidate 不授予 Product Phase 4、contract/Release-v2 implementation、seal、publication、Latest 或 rollback
变更；只有活动 task plan 可以授权下一 gate。
