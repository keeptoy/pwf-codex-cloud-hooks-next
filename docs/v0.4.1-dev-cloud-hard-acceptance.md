<a name="v0-4-1-dev-path-safety-delta"></a>

## Path-safety acceptance delta

本版本新增installer路径拓扑边界：`hooks` parent、runtime root或runtime内部entry若为symlink、junction或special
path，install、repair与uninstall都必须在backup和任何shared/runtime mutation前fail closed。uninstall对unknown
普通文件/目录的recovery/cleanup合同保持不变。

本增量由installer边界测试与published round-trip transition oracle验证；Cloud执行仍复用模板的
[`Source/Candidate setup`](cloud-hard-acceptance-template.md#source-candidate-setup)和
[`Source/Candidate deep check`](cloud-hard-acceptance-template.md#source-candidate-deep-check)。B～E黑盒提示词、Host ABI、
adapter-only policy与runtime dispatch均未改变。

当前结论：`LOCAL_PATH_SAFETY_PASS / LINUX_AND_CLOUD_PENDING / RELEASE_NOT_AUTHORIZED`。
